Put de440s.bsp (NASA JPL, 32 MB) here, or de440.bsp for 1550-2650.
If it is missing, sky_engine.load() looks in $SKY_EPHEM_DIR, then downloads de440s.bsp from
https://ssd.jpl.nasa.gov/ftp/eph/planets/bsp/ into this folder (the Windows desktop copy
downloads into %LOCALAPPDATA%\SkyPaschalion\ephem instead and looks there too).
